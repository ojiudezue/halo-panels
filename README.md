# Halo

An opt-in Home Assistant integration that drives the house wall panels (Kiosk Satellite tablets): LED ring indications for safety and security, announcements and on-screen cards, with priority arbitration, restore and a sleep rule owned here.

Universal Room Automation (URA) uses Halo as one Notification Manager delivery channel: URA decides which rooms, Halo decides what each panel shows.
